# BBL TACTICS 🛡️

Tactical RPG au tour par tour en 3D rétro (style PS1), **conçu d'abord pour le téléphone**, avec
les potes de [BBL FIGHTERZ](https://github.com/Callme-Roby/BBL-Fighterz) : mêmes persos 3D
low-poly avec leurs photos de visage, mêmes animations, mêmes musiques.

> Projet en cours de construction — voir l'historique des commits pour l'avancement.

## Lancer en local

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # build de prod dans dist/
npm test           # tests automatiques (formules, cartes, IA)
```

Déploiement : comme BBL FIGHTERZ, site statique Vite sur Vercel (`vercel.json`).
